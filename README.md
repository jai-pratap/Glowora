# Glowora— Skin & Hair Wellness Website

A responsive, multi-page student project built with **HTML, CSS and vanilla JavaScript only**.

## Pages
- `index.html` — Home page
- `quiz.html` — Skin and hair check-in quizzes
- `routine.html` — Custom routine builder and daily tracker
- `ingredients.html` — Searchable ingredient guide
- `dashboard.html` — Assessment summaries and routine progress
- `tips.html` — Searchable skin, scalp and hair-care tips

## Run locally
1. Download and unzip the project.
2. Open the `dermabloom` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Navigate using the top menu.

No package installation, build step, Python, or backend is required.

## Data and privacy
The project uses browser LocalStorage to save assessment summaries, routines, checkmarks and theme preference on the current device/browser. Data is not synced between devices and can be cleared when browser storage is cleared.

## Notes
- The assessment is educational and does not diagnose medical conditions.
- Product and ingredient information is general educational content, not treatment advice.
- The homepage uses a remote Unsplash image and Google Fonts; the rest of the app works without them.
- For a production version, review accessibility, content accuracy, privacy, and clinical safety with qualified professionals.
